# 🏥 Insurance Data Analysis

## 📌 Project Overview
This project focuses on exploring and analyzing insurance data using Python. It uses Exploratory Data Analysis (EDA), data cleaning, preprocessing, feature engineering, and statistical techniques to understand the factors associated with medical insurance charges.

## 🎯 Objectives
- Understand the insurance dataset through EDA.
- Identify missing values and duplicate records.
- Analyze numerical and categorical variables.
- Visualize data distributions and correlations.
- Perform data cleaning and preprocessing.
- Apply feature engineering techniques.
- Analyze relationships between features and insurance charges.

## 📂 Dataset Information
The dataset contains **1,338 records and 7 columns**.

| Column | Description |
|---|---|
| age | Age of the individual |
| sex | Gender |
| bmi | Body Mass Index |
| children | Number of children |
| smoker | Smoking status |
| region | Residential region |
| charges | Medical insurance charges |

## 🚀 How to Run the Project

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd Insurance-Analysis
```

3. Install the required libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn scipy jupyter
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `Insurance.ipynb` and run the cells.
